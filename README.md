## 快速开始

使用文件导入：

1. 从 [Releases](https://github.com/isxiaojian/MyTab/releases) 下载 .CRX 或 .ZIP 文件
2. 打开浏览器的扩展/插件管理界面，启用开发人员模式
3. 将下载的 .CRX 或 .ZIP 文件拖入插件界面导入
4. 在插件列表找到 MyTab 启用
- ***请注意，如果无法启用请使用 .zip 导入***


## 关于 MyTab

<img alt="215014" src="docs/pics/2002.webp" />

- 面向桌面浏览器可定制的类原生浏览器起始页
- 没有无关紧要的在线内容，提升了新标签页的加载速度
- 在相对更多个性化的同时也可以享受到极致的速度


## 特色功能

- 随意更改搜索引擎，logo 标题、网站导航、搜索历史、搜索框位置由您决定
- 自定义背景、搜索引擎以及布局
- 固定您想放在此处的网站
- 亦或是任意一个壁纸

## 适用范围

- **系统**：Windows 7 以上 / macOS 10.15 以上 / Linux 至少支持现代 GTK 3 的发行版
- **浏览器**：
  - Chrome / Edge：109 以上
  - Firefox：109 及以上
- **支持语言**：简体中文 / 繁體中文 / English / Русский / 日本語
